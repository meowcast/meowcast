# Code of conduct

Be kind, be specific, assume good faith.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: no harassment, no personal attacks, no publishing of other people's private
information; criticism is about the work, not the person.

Report a problem to the maintainers through a private message to an organisation owner on
GitHub. Reports are handled confidentially.
